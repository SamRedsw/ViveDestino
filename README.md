# ViveDestino - API REST Enterprise BackendViveDestino es una API RESTful desarrollada en Java 21 y Spring Boot para lacomercializacion, reserva y control logistico de experiencias turisticas denaturaleza, cultura y gastronomia. El sistema centraliza la operacion paraviajeros, operadores turisticos, guias y administradores, garantizando latrazabilidad en transacciones, disponibilidad de cupos y calificaciones reales.---### Equipo de Desarrollo*Samuel Felipe Rojas Molina**Dayron Geovanny Pachon Cardenas**Ana Jimena Acosta Aguilera**Siman Gomez **Nikolas Alberto Rodriguez Tovar*### ️ Tecnologias Utilizadas*Lenguaje:* Java 21*Framework Backend:* Spring Boot 3.x*Persistencia de Datos:* Spring Data JPA / Hibernate*Base de Datos:* PostgreSQL / Supabase*Seguridad:* Spring Security + JWT (JSON Web Tokens)*Seguridad de Contraseñas:* BCrypt*Documentacion:* OpenAPI 3 / Swagger UI*Herramientas Adicionales:* Lombok, Jakarta Validation## Requisitos PreviosPara compilar y ejecutar el proyecto localmente, se debe tener instalado:1. Java JDK 21 o superior.2. Apache Maven 3.8+ (o utilizar el ejecutable ./mvnw incluido en el proyecto).3. PostgreSQL** instalado o credenciales de conexion a Supabase.## Guia de Instalacion y EjecucionPasos para clonar, configurar y ejecutar el proyecto desde un entorno limpio:### 1. Clonar el Repositoriogit clone [https://github.com/SamRedsw/ViveDestino.git](https://github.com/SamRedsw/ViveDestino.git)cd ViveDestino### 2. Configurar las Variables de Entorno / Base de DatosAbre el archivo src/main/resources/application.properties y configura las credenciales de tu base de datos:spring.application.name=ViveDestino# Configuracion de Base de Datos PostgreSQL / Supabasespring.datasource.url=jdbc:postgresql://localhost:5432/vivedestino_dbspring.datasource.username=postgresspring.datasource.password=tu_contraseñaspring.jpa.hibernate.ddl-auto=updatespring.jpa.show-sql=truespring.jpa.properties.hibernate.format_sql=true### 3. Ejecutar la AplicacionArrancar la aplicacion desde la terminal utilizando el Wrapper de Maven:./mvnw spring-boot:run### 4. Documentacion Interactiva de la API (Swagger UI)Una vez iniciada la aplicacion, la documentacion interactiva OpenAPI/Swaggerestara disponible en la siguiente URL: http://localhost:8080/swagger-ui/index.html### 5. Autenticacion y Cuentas de PruebaLa API utiliza seguridad basada en Tokens JWT. Para probar las rutas protegidas enSwagger o Postman:a.Haz una peticion POST al endpoint /api/usuarios/login enviando las credenciales.b.Copia el token JWT de la respuesta (token).c.En Swagger UI, haz clic en el boton Authorize (candado) e ingresa el tokencon el formato: Bearer TU_TOKEN_JWT.### Principales Endpoints REST Expuestosa.Autenticacion y UsuariosPOST /api/usuarios - Registrar un nuevo usuario (Publico).POST /api/usuarios/login - Iniciar sesion y obtener token JWT (Publico).GET /api/usuarios - Listar todos los usuarios registrados (Autenticado).b.Experiencias Turisticas:GET /api/experiencias - Consultar experiencias publicas/activas (Publico).GET /api/experiencias/{id} - Obtener detalle tecnico e itinerario de una experiencia (Publico).POST /api/experiencias - Crear nueva experiencia turistica (Rol: ORGANIZADOR, ADMINISTRADOR).c.Salidas Operativas:GET /api/salidas/experiencia/{id} - Obtener salidas programadas por experiencia (Publico).POST /api/salidas - Programar salida asignando fecha, hora, cupos y guía (Rol: ORGANIZADOR, ADMINISTRADOR).d.Reservas y Pagos:POST /api/reservas - Apartar cupos/plazas en una salida (Rol: VIAJERO).POST /api/pagos - Procesar pago simulado atomico de una reserva (Rol: VIAJERO).PUT /api/reservas/{id}/cancelar - Cancelar reserva y liberar cupos (Rol: VIAJERO).e.Asistencia y Calificaciones:PUT /api/reservas/{id}/marcar-asistencia - Marcar asistencia del viajero a la salida (Rol: GUIA, ADMINISTRADOR).POST /api/calificaciones - Registrar reseña de 1 a 5 estrellas (Solo viajeros con asistencia confirmada).GET /api/calificaciones/experiencia/{id} - Consultar calificaciones y opiniones de una experiencia.f.Reportes Analiticos:GET /api/admin/reportes/ventas - Reporte consolidado de ingresos y transacciones (Rol: ADMINISTRADOR).GET /api/admin/reportes/experiencias-demandadas - Ranking de experiencias con más reservas (Rol: ADMINISTRADOR).GET /api/admin/reportes/calificaciones - Consolidado de satisfaccion promedio (Rol: ADMINISTRADOR).## Referencias![Java](https://img.shields.io/badge/Java-21-orange?style=for-the-badge&logo=java)![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.3.4-brightgreen?style=for-the-badge&logo=springboot)![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Supabase-blue?style=for-the-badge&logo=postgresql)![JWT](https://img.shields.io/badge/JWT-Authentication-red?style=for-the-badge&logo=jsonwebtokens)![Swagger](https://img.shields.io/badge/Swagger-OpenAPI_3.0-green?style=for-the-badge&logo=swagger)
