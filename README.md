# ViveDestino - API REST Enterprise Backend![Java](https://img.shields.io/badge/Java-21-orange?style=for-the-badge&logo=java)![Spring Boot](https://img.shields.io/badge/Spring_Boot-3.3.4-brightgreen?style=for-the-badge&logo=springboot)![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Supabase-blue?style=for-the-badge&logo=postgresql)![JWT](https://img.shields.io/badge/JWT-Authentication-red?style=for-the-badge&logo=jsonwebtokens)![Swagger](https://img.shields.io/badge/Swagger-OpenAPI_3.0-green?style=for-the-badge&logo=swagger)**ViveDestino** es una plataforma tecnológica para la gestión, reserva y comercialización de experiencias turísticas y ecoturísticas. Su arquitectura backend está desarrollada con Spring Boot 3 y se conecta a una base de datos relacional PostgreSQL alojada en la nube (Supabase), aplicando control de acceso basado en roles (RBAC) mediante JWT.---##  Tecnologías y Herramientas* **Lenguaje:** Java 21* **Framework Principal:** Spring Boot 3.3.4* **Persistencia de Datos:** Spring Data JPA / Hibernate* **Motor de Base de Datos:** PostgreSQL (Instancia en Supabase Cloud)* **Seguridad & Autenticación:** Spring Security 6 + JSON Web Tokens (JWT)* **Documentación Interactiva:** OpenAPI 3.0 / Swagger UI* **Herramientas de Productividad:** Lombok, Jakarta Validation* **Gestor de Dependencias:** Apache Maven---##  Arquitectura y Capas del SistemaEl proyecto implementa una arquitectura multicapa desacoplada y escalable:
